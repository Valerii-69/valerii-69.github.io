Учебник: Трёхзвучный пентатонический сон

Описание синтезатора

Этот синтезатор создаёт стерео-трёхзвучные мелодии на основе пентатонической шкалы. Каждый сон формируется как последовательность трёхнотных аккордов с плавной атакой/затуханием, панорамой и реверберацией. Можно также сохранить результат в WAV.

Элементы интерфейса

  • Название сна: введите любую строку — синтезатор создаст уникальную мелодию.
  • Сгенерировать сон: создаёт и проигрывает сон на основе введённого названия.
  • Записать WAV: сохраняет текущий сон в формате WAV.
  • Canvas: отображает визуализацию волны в реальном времени с цветовыми эффектами.
  • Тональность: показывает базовую частоту трезвучий.

Принцип работы

  1. Строка названия преобразуется в числовой seed для повторяемой генерации.
  2. Генерируется последовательность трёхнотных аккордов из пентатонической шкалы.
  3. Применяется огибающая атака/затухание (attack/release) для плавности звучания.
  4. Добавляется панорама для стереоэффекта и реверберация.
  5. Визуализация отображает динамику звучания и плавно изменяет фон.
  6. Можно объединить несколько трёхзвучий через кроссфейд.
  7. Результат можно воспроизвести или записать в WAV.

Советы по экспериментам

  • Меняйте название сна — каждый вариант создаёт уникальную мелодию.
  • Следите за визуализацией: она отражает ритм и амплитуду звукового потока.
  • Экспериментируйте с разными длинами названия и количеством гласных — это влияет на длину фраз, реверберацию и кроссфейд.
  • Используйте запись WAV для анализа или сохранения любимых мелодий.

Пример использования

Введите название сна: Звёздная пыль, нажмите Сгенерировать сон. После прослушивания нажмите Записать WAV, чтобы сохранить файл.

Основные функции

  • stringToSeed(str): преобразует строку названия в числовой seed для генерации случайных чисел.
  • seededRandom(seed): возвращает функцию генерации псевдослучайных чисел для повторяемой генерации.
  • parseDreamName(name): анализирует название сна, определяет базовую частоту, длину мелодии, количество снов и реверберацию.
  • generateDream(freqBase, scale, duration, rand): создаёт трёхзвучные мелодии с панорамой и огибающей.
  • addReverb(stereo, amount): добавляет реверберацию к стерео-сигналу.
  • mergeDreams(dreams, crossfadeTime): объединяет несколько трёхзвучий с плавным переходом.
  • playBuffer(stereo): воспроизводит трёхзвучие через аудиоконтекст.
  • exportWav(stereo): экспортирует текущий сон в WAV-файл.
  • visualize(data): визуализирует звуковую волну и плавно меняет фон страницы.
