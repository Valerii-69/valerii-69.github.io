Учебник — Синтезатор «Музыкальный лабиринт» (guide1)

Кратко: этот синтезатор — сетка 7×7 ячеек, каждая ячейка несёт свою группу гармоник. При касании (или клике) ячейки либо проигрывается сэмпл, либо генерируется комбинация осцилляторов (режим synth). Есть транспозер, регулировка затухания и число повторов (стак эффектов).

Что вы услышите

  • В режиме synth — богатое «пилообразное» звучание (sawtooth), где каждая ячейка запускает набор гармоник.
  • В режиме sample — загруженные вами аудиофайлы воспроизводятся с наложением повторов и плавным спадом громкости.
  • Транспозиция (transpose) сдвигает все активные ноты в реальном времени — можно получить эффект хорового смещения.
  • Параметры repeats и release управляют плотностью слоёв и длиной затухания соответственно.

Что можно настроить и исследовать

Практические идеи:
  • Увеличьте repeats и уменьшите release — получите звуковую «стяжку», как ритмический паттерн.
  • Поставьте mode в sample и загрузите короткие ударные сэмплы — сетка превратится в драм-машину.
  • Экспериментируйте с транспозером: плавное движение слайдера создаёт глиссандо у всех активных осцилляторов.
  • Измените форму осциллятора (sine/square/triangle) в коде playSynth — тембр резко поменяется.

Ключевые моменты в коде (готово к копированию)

1) Инициализация AudioContext и базовые структуры

// создаём AudioContext и хранилища
let audioCtx = new (window.AudioContext || window.webkitAudioContext)();
const size = 7;
const cells = [];
const cellHarmonics = new Map();
let buffers = [];               // Array<AudioBuffer> для режима sample
let activeOscillators = new Map(); // отслеживаем запущенные осцилляторы

2) Создание сетки 7×7 (DOM)

// добавляем ячейки в контейнер gridEl
for (let y = 0; y < size; y++) {
  for (let x = 0; x < size; x++) {
    const cell = document.createElement('span');
    cell.className = 'cell';
    cell.dataset.x = x;
    cell.dataset.y = y;
    gridEl.appendChild(cell);
    cells.push(cell);
    // cellHarmonics.set(cell, [...]) — задаём позже
  }
}

3) Воспроизведение синтеза (playSynth)

function playSynth(idx, cell) {
  const repeat = Number(repeatsSlider.value) || 1;
  const release = Number(releaseSlider.value) || 20;
  const trans = Number(transposeSlider.value) || 0;
  const baseFreq = 261.63; // C4
  const harmonics = cellHarmonics.get(cell) || [1];

  harmonics.forEach(mult => {
    for (let i = 0; i < repeat; i++) {
      const osc = audioCtx.createOscillator();
      osc.type = 'sawtooth'; // попробуйте 'sine','square','triangle'
      const freq = baseFreq * mult * Math.pow(2, (idx + trans) / 12);
      osc.frequency.value = freq;

      const gain = audioCtx.createGain();
      gain.gain.setValueAtTime(0.5 / repeat, audioCtx.currentTime + i * 0.05);
      gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + i * 0.05 + release * 0.05);

      osc.connect(gain).connect(audioCtx.destination);
      osc.start(audioCtx.currentTime + i * 0.05);
      osc.stop(audioCtx.currentTime + i * 0.05 + release * 0.05);

      activeOscillators.set(osc, { idx, gain });
      osc.onended = () => activeOscillators.delete(osc);
    }
  });
}

4) Воспроизведение сэмплов (playSample)

async function playSample(idx) {
  if (!buffers.length) return;
  const repeat = Number(repeatsSlider.value) || 1;
  const release = Number(releaseSlider.value) || 20;
  const buffer = buffers[idx % buffers.length];

  for (let i = 0; i < repeat; i++) {
    const src = audioCtx.createBufferSource();
    src.buffer = buffer;
    const gain = audioCtx.createGain();
    gain.gain.setValueAtTime(1, audioCtx.currentTime + i * 0.05);
    gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + i * 0.05 + release * 0.05);
    src.connect(gain).connect(audioCtx.destination);
    src.start(audioCtx.currentTime + i * 0.05);
  }
}

5) Загрузка файлов в buffers (input[type=file])

sampleInput.addEventListener('change', async (e) => {
  const files = Array.from(e.target.files);
  buffers = [];
  for (let f of files) {
    const ab = await f.arrayBuffer();
    const buf = await audioCtx.decodeAudioData(ab);
    buffers.push(buf);
  }
  sampleStatus.textContent = `${buffers.length} файлов`;
});

6) Транспозиция в реальном времени

transposeSlider.addEventListener('input', () => {
  transposeValue.textContent = transposeSlider.value;
  const trans = Number(transposeSlider.value);
  // меняем частоту всех активных осцилляторов
  activeOscillators.forEach(({ idx }, osc) => {
    const freq = 261.63 * Math.pow(2, (idx + trans) / 12);
    osc.frequency.setValueAtTime(freq, audioCtx.currentTime);
  });
});

Рекомендации и советы

  • Если браузер блокирует звук — вызовите audioCtx.resume() в ответ на пользовательский клик/касание.
  • Для меньшей загрузки CPU замените фрактальную визуализацию на простой canvas-паттерн или отключите её вовсе.
  • Чтобы управлять тоном более музыкально, сохраняйте для каждой ячейки не индекс idx, а заранее вычисленные частоты (в герцах).
  • Добавьте BiquadFilterNode перед выходом в destination, чтобы смягчать высокий спектр sawtooth.

Короткий чек-лист для тестирования

  • Нажмите New — сетка получила гармоники (цвета тоже).
  • Нажмите на ячейку в режиме synth — должен прозвучать тон.
  • Переключитесь в sample, загрузите хотя бы один файл — при касании должна играть запись.
  • Покрутите транспозер — активные осцилляторы меняют высоту.
  • Нажмите Stop — все осцилляторы должны остановиться.
