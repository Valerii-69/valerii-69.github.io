Учебник: Генератор пентатонических снов

Описание синтезатора

Синтезатор 7 создаёт несколько пентатонических снов, объединяет их с кроссфейдом, добавляет реверберацию и визуализирует результат на canvas. Каждое воспроизведение создаёт уникальную комбинацию звуков, которые можно сохранить в WAV.

Элементы интерфейса

  • Число снов: количество отдельных мелодий, которые будут объединены.
  • Длительность сна (сек): длительность каждой мелодии.
  • Сила реверба: интенсивность эффекта реверберации.
  • Скорость кроссфейда (сек): плавность перехода между мелодиями.
  • Сгенерировать и проиграть: создаёт комбинированную мелодию, визуализирует её и проигрывает.
  • Canvas: отображает визуализацию звуковых волн.
  • Скачать WAV: появляется ссылка для сохранения комбинированного сна.

Принцип работы

  1. Генерируются случайные базовые частоты для каждой мелодии.
  2. Выбирается случайная пентатоническая шкала для каждого сна.
  3. Создаётся аудиобуфер с синусоидными волнами.
  4. Применяется реверберация для глубины звука.
  5. Мелодии объединяются с заданным crossfade.
  6. Производится визуализация на canvas.
  7. Воспроизводится через AudioContext и предоставляется ссылка для скачивания WAV.

Советы по экспериментам

  • Увеличьте число снов для более сложной текстуры мелодии.
  • Меняйте длительность сна для коротких или длинных фраз.
  • Используйте реверберацию для создания пространства и атмосферы.
  • Пробуйте разные значения crossfade для более плавного или резкого соединения мелодий.
  • Каждое воспроизведение создаёт уникальный сон благодаря случайным базовым частотам и выбору шкалы.

Пример использования

Установите число снов = 5, длительность сна = 3 сек, реверб = 0.3, кроссфейд = 0.5. Нажмите 🎧 Сгенерировать и проиграть. После прослушивания появится ссылка 💾 Скачать WAV.

Основные функции синтезатора

  • generateDream(freqBase, scale, duration): создаёт одну пентатоническую мелодию.
  • addReverb(signal, amount): применяет простую реверберацию.
  • mergeDreams(dreams, crossfadeTime): объединяет несколько мелодий с кроссфейдом.
  • visualize(canvas, buffer): отображает амплитуду звука на canvas.
  • encodeWAV(samples, sampleRate): преобразует аудиобуфер в WAV для скачивания.
