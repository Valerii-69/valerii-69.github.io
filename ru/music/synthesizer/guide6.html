Учебник: Пентатонический сон

Описание синтезатора

Синтезатор создаёт стерео-трёхзвучные мелодии на основе пентатонической шкалы. Он использует название сна для генерации случайных, но повторяемых мелодий с заданной базовой нотой, темпом, панорамой, атакой и затуханием. Можно также сохранить сон в WAV.

Элементы интерфейса

  • Название сна: строка, которая определяет уникальную мелодию.
  • Базовая нота: выбирается из пентатоники (C, D, E, G, A).
  • Темп (BPM): скорость проигрывания мелодии.
  • Crossfade: плавный переход между нотами/фразами.
  • Атака/Затухание: регулировка огибающей каждой ноты.
  • Панорама: положение звука в стерео (левая/правая сторона).
  • Сгенерировать сон: создаёт мелодию и визуализацию на canvas.
  • Записать WAV: сохраняет текущий сон в WAV-файл.
  • Canvas: отображает визуализацию звуковых волн с динамическим фоном.
  • Тональность: показывает базовую ноту и темп.

Принцип работы

  1. Название сна преобразуется в числовой seed для повторяемой генерации случайных чисел.
  2. Определяется октава на основе соотношения гласных и согласных.
  3. Создаётся массив частот для пентатонической шкалы.
  4. Генерируется аудиобуфер с трёхзвучными фразами с огибающей атаки и затухания, панорамой и реверберацией.
  5. Аудиобуфер воспроизводится через AudioContext, а waveform визуализируется на canvas.
  6. Можно экспортировать аудиобуфер в WAV-файл.

Советы по экспериментам

  • Меняйте название сна для создания уникальных мелодий.
  • Экспериментируйте с базовой нотой — она меняет тональность всей мелодии.
  • Плавно регулируйте атаки и release для более мягкого или резкого звучания.
  • Используйте crossfade для создания плавных переходов между фразами.
  • Панорама позволяет создавать ощущение движения звука в пространстве.
  • Темп влияет на длительность фраз и ритмику.
  • Сохраняйте любимые мелодии через WAV для дальнейшего прослушивания или анализа.

Пример использования

Введите название сна: Ночной ветер, выберите базовую ноту: E, темп 100 BPM. Нажмите Сгенерировать сон. После прослушивания нажмите Записать WAV для сохранения файла.

Основные функции

  • stringToSeed(str): преобразует название сна в числовой seed для генератора случайных чисел.
  • seededRandom(seed): возвращает функцию повторяемой генерации псевдослучайных чисел.
  • parseDreamName(name): анализирует название сна, определяет октаву, реверберацию, длину фраз и crossfade.
  • noteToFreq(note, octave): преобразует ноту и октаву в частоту.
  • generateDreamAudio(params): создаёт аудиобуфер с трёхзвучными фразами.
  • playDream(buffer): воспроизводит аудиобуфер с визуализацией на canvas.
  • exportWav(buffer): сохраняет текущий сон в WAV-файл.
