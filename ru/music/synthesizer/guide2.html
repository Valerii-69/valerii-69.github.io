🎧 Guide 2 — Ноты и ADSR

Что делает этот синтезатор

Этот синтезатор позволяет услышать, как из простой формы волны рождается нота с динамической огибающей. При каждом нажатии кнопки «Проиграть ноту» генерируется выбранная частота (например, A4 = 440 Гц) и формируется звуковая волна заданного типа — синус, квадрат, пила, треугольник или трапеция.

Основная идея — исследовать, как параметры ADSR (Attack, Decay, Sustain, Release) формируют характер звучания. Это модель развития громкости во времени: от мягкого начала до затухания после отпускания ноты.

Что можно услышать и настроить

Выберите ноту (A2–A5), изменяйте тип волны и параметры ADSR. Попробуйте короткий Attack и длинный Release — звук станет более «певучим». Увеличьте Decay и уменьшите Sustain — получите характерный «удар» клавишного инструмента.

Ключевые фрагменты кода

1. Инициализация и подготовка аудиоконтекста


let audioCtx;

function ensureAudio() {
  if (!audioCtx) {
    audioCtx = new (window.AudioContext || window.webkitAudioContext)();
  }
}

2. Формирование огибающей ADSR


const now = audioCtx.currentTime;
gain.gain.cancelScheduledValues(now);
gain.gain.setValueAtTime(0, now);
gain.gain.linearRampToValueAtTime(0.8, now + a);         // Attack
gain.gain.linearRampToValueAtTime(s, now + a + d);       // Decay → Sustain
gain.gain.setValueAtTime(s, now + a + d + 0.2);
gain.gain.linearRampToValueAtTime(0, now + a + d + 0.2 + r); // Release

3. Выбор формы волны


if (waveType === 'custom') {
  const real = new Float32Array([0, 1, 0.5, 0.25, 0.1]);
  const imag = new Float32Array(real.length);
  osc.setPeriodicWave(audioCtx.createPeriodicWave(real, imag));
} else {
  osc.type = waveType;

4. Отрисовка огибающей ADSR


function drawEnvelope(a, d, s, r) {
  const width = envCanvas.width;
  const height = envCanvas.height;
  const total = a + d + r + 0.2;

  ectx.beginPath();
  ectx.moveTo(0, height);
  ectx.lineTo(width * (a / total), 0);
  ectx.lineTo(width * ((a + d) / total), height * (1 - s));
  ectx.lineTo(width * ((a + d + 0.2) / total), height * (1 - s));
  ectx.lineTo(width, height);
  ectx.stroke();
}

Итог

Этот синтезатор — простая лаборатория для изучения динамики звука. Здесь можно наблюдать, как геометрия формы волны сочетается с временной структурой ADSR. Идеально подходит для экспериментов с восприятием атаки, затухания и послезвучия.
