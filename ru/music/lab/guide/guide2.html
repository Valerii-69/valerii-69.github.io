Учебник: Пентатоническая лаборатория

Цель эксперимента

Лаборатория позволяет исследовать звучание пентатонической гаммы — набора из пяти звуков, образующих гармоничные созвучия без полутонов. Здесь можно управлять тембром, интервалами, полифонией и наблюдать живую осциллограмму звука.

Основные модули

1. Matrix (нотовая матрица)

Генерирует пентатонический ряд от выбранной базовой ноты. Кнопки нот активируют соответствующие частоты, построенные по выбранной модели (12-TET, пифагорейская и т.д.).

2. AudioEngine

Использует AudioContext и осцилляторы Web Audio API. Каждый голос создаётся с параметрами osc.type (волна) и gain (громкость). Звук обрабатывается через AnalyserNode и реверберацию.

3. Transposer

Отвечает за интервалы и полифонию — добавление терций, квинт, трезвучий и их расщепление на несколько голосов. Используются интервальные пресеты: {note:[0], third:[0,4], fifth:[0,7], triad:[0,4,7]}.

4. Oscilloscope

Реализован через Canvas. Отображает осциллограмму в реальном времени, используя данные из AnalyserNode.getByteTimeDomainData(). Линия визуализируется градиентом — фиолетовый, бирюзовый, сиреневый.

Математические модели частот

Выбор математической модели позволяет сравнить разные музыкальные строи.

  • 12-TET — равномерная темперация, стандарт для фортепиано и синтезаторов.
  • Пифагорейская — интервалы строятся на чистых квинтах 3:2.
  • Чистая интонация — частоты выражаются простыми дробями m/n.
  • Гармонический ряд — каждый звук = k-ая гармоника базовой частоты.

Пример формулы для 12-TET: f = f0 * 2^((n - n0)/12)

Интерактивный пример

Попробуй изменить базовую ноту и нажать «Проиграть ряд». Осциллограмма изменится в реальном времени.


// Пример кода проигрывания ряда
function playRowSequential() {
  const pent = generatePentSet(currentBaseIndex);
  let t = 0;
  for (const n of pent) {
    setTimeout(() => playChord([n]), t * 1000);
    t += 0.5;
  }
}

Как работает полифония

Для каждого нота создаются несколько осцилляторов, слегка расстроенных между собой (на ±6 центов) и панорамированных влево и вправо. Это создаёт эффект пространственного звучания.

Советы для экспериментов

  • Слушай через наушники — так лучше ощущается пространственная панорама.
  • Попробуй чередовать волны: triangle для мягкости, sawtooth для насыщенности.
  • Сравни гармонический ряд с равномерной темперацией и почувствуй разницу.
