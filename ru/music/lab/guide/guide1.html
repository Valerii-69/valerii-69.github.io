Учебник к лабораторной работе
«Интро: Путешествие по Лаборатории»

Этот учебный модуль объясняет, как работает первая страница Лаборатории. Здесь вы познакомитесь с основами Web Audio API и создадите свой первый «звучащий круг».

1. Идея эксперимента

Главная цель интро — показать, что каждая ячейка Лаборатории может оживать, превращаясь в музыкальный элемент. Вся магия строится на трёх вещах:

  • AudioContext — создаёт звуковое пространство браузера;
  • OscillatorNode — генерирует звук определённой частоты;
  • ConvolverNode — создаёт эффект эха или реверберации.

2. Ключевой фрагмент кода

const ctx = new (window.AudioContext || window.webkitAudioContext)();
const osc = ctx.createOscillator();
const gain = ctx.createGain();
const reverb = ctx.createConvolver();

// создаём короткую "импульсную характеристику" — эхо
const len = ctx.sampleRate * 1.2;
const impulse = ctx.createBuffer(2, len, ctx.sampleRate);
for (let ch = 0; ch < 2; ch++) {
  const data = impulse.getChannelData(ch);
  for (let i = 0; i < len; i++) {
    data[i] = (Math.random() * 2 - 1) * Math.pow(1 - i / len, 2.5);
  }
}
reverb.buffer = impulse;

// подключаем узлы
osc.connect(gain);
gain.connect(reverb);
reverb.connect(ctx.destination);
Здесь создаётся простая модель “зала”, где звук постепенно затухает. При каждом нажатии частота немного меняется — как будто вы делаете шаг по новой комнате лабиринта.

4. Что происходит под капотом

Каждый раз, когда вы нажимаете на кнопку, скрипт:

  1. создаёт новый AudioContext,
  2. выбирает случайную ноту рядом с ля (A4 = 440 Гц),
  3. плавно увеличивает громкость, затем уменьшает её,
  4. добавляет лёгкий реверб, чтобы звук “жил” чуть дольше.

5. Эксперимент для читателя

Попробуйте изменить параметры в коде: freq = baseFreq * Math.pow(2, randSemitone / 12) — это формула, переводящая интервалы в герцы. Если заменить 12 на 24, шаг между тонами станет вдвое меньше, и звуки будут ближе друг к другу.
