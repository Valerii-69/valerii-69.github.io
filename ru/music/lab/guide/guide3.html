🧭 Гид по JavaScript — Лаборатория читателя

1. Переменные и типы данных

В JavaScript можно хранить данные разных типов: числа, строки, логические значения, объекты и многое другое.

// Примеры переменных
let имя = "Валерий";
let возраст = 72;
let активен = true;

console.log("Привет,", имя);
console.log("Возраст:", возраст);

Для объявления переменных используются let и const. Разница в том, что const нельзя изменить.

2. Функции и взаимодействие

Функции позволяют собирать логику в удобные блоки кода. Например, создадим простую функцию приветствия:

function приветствие(имя) {
  return "Привет, " + имя + "!";
}

console.log(приветствие("читатель"));

Функции можно передавать как значения, хранить в переменных и даже возвращать из других функций — это даёт невероятную гибкость.

3. Манипуляции с HTML

JavaScript может изменять содержимое страницы на лету. Вот пример динамического изменения текста:

<button onclick="изменитьТекст()">Нажми меня</button>
<p id="demo">Привет!</p>

<script>
function изменитьТекст() {
  document.getElementById("demo").innerText = "Ты изменил текст!";
}
</script>

Так можно создавать интерактивные элементы прямо внутри страницы лаборатории.
