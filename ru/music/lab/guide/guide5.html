🎧 Учебник: «Сэмплы — Загрузка локально»

1. Назначение эксперимента

Эта лабораторная страница позволяет подгружать собственные аудиофайлы прямо с устройства — будь то отдельные звуки, сэмплы или целые коллекции из папки /samples.

Браузер не имеет доступа к файловой системе напрямую: вы разрешаете чтение только тех файлов, которые выберете вручную через <input type="file">. Это ограничение встроено в систему безопасности — чтобы веб-страницы не могли заглядывать в личные каталоги.

2. Как работает загрузка

После выбора файлов элемент input передаёт массив FileList. Код обходит его, создаёт визуальный список и кнопку «Play» для каждого файла. 

fileEl.addEventListener('change', async (e) => {
  const files = Array.from(e.target.files);
  list.innerHTML = '';
  for (const f of files) {
    const el = document.createElement('div');
    el.className = 'sample';
    el.textContent = f.name;
    const play = document.createElement('button');
    play.textContent = 'Play';
    el.appendChild(play);
    list.appendChild(el);
  }
});

Так создаётся динамическая галерея — маленький каталог ваших звуков.

3. Воспроизведение через Web Audio API

Для каждого файла при нажатии кнопки создаётся объект AudioContext, в котором звук декодируется и проигрывается как буфер. 

play.addEventListener('click', async () => {
  if (!ctx) ctx = new (window.AudioContext || window.webkitAudioContext)();
  const arr = await f.arrayBuffer();
  const buf = await ctx.decodeAudioData(arr.slice(0));
  const s = ctx.createBufferSource();
  s.buffer = buf;
  s.connect(ctx.destination);
  s.start();
});

Здесь браузер превращает байты файла в цифровую волну. Звук не стримится, а загружается целиком, чтобы проигрыватель мог точно контролировать его начало и конец.

4. Возможности расширения

— Добавь визуализацию частот с помощью AnalyserNode — получится живой спектр. — Или задай каждому сэмплу собственную громкость, панораму, фильтр. — Можно объединять несколько буферов в один микс и строить многослойные коллажи.

Так простая загрузка превращается в первый шаг к собственной цифровой студии.

5. Почему «локально»?

Потому что это напоминает старые аналоговые эксперименты: всё рядом, под рукой. Звук становится личным материалом, а не загруженным из облака. Каждый WAV — это фрагмент памяти, и лаборатория даёт возможность слушать их как части акустической биографии.
