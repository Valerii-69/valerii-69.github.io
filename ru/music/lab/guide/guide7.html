1. Идея генератора

Мы создаём простую мелодическую идею, основанную на детерминированной случайности. Это значит, что одна и та же тема даёт один и тот же результат, как будто у нас «ИИ с памятью».

2. Преобразование текста в число

ВНИМАНИЕ СПРАВКА: Чтобы браузер не испортил код (перепутав угловые скобки с HTML-тегами), мы экранируем символы <, > и &. Затем библиотека highlight.js раскрашивает синтаксис. Это и есть безопасный вывод кода.

function hashSeed(s) {
  let h = 0;
  for (let i = 0; i < s.length; i++) {
    h = (h * 31 + s.charCodeAt(i)) | 0;
  }
  return Math.abs(h);
}

Каждый символ текста влияет на число — seed, задающее последовательность «случайных» чисел.

3. Генерация мелодии


const base = 60 + (seed % 12); // базовая нота
const scale = [0, 2, 3, 5, 7, 9, 10]; // диатоника
const seq = [];

for (let i = 0; i < 8; i++) {
  const r = Math.floor(rng() * scale.length);
  seq.push(scale[r]);
}

Массив интервалов scale задаёт структуру ладов, а генератор rng() выбирает случайные ноты относительно базовой. Результат будет одинаков при одинаковом seed.

4. Эмуляция ИИ через детерминированную случайность

Мы не используем нейросети, но воспроизводим иллюзию «ума» за счёт предсказуемой случайности. Алгоритм линейной конгруэнции (LCG) генерирует одинаковые последовательности при одном и том же seed.
