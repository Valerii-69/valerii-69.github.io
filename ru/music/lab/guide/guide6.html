🎶 Учебник: «Генератор — Хаос и мелодия»

1. Идея генератора

Этот генератор создаёт короткие мелодические фразы, где хаотическая случайность подчиняется простому правилу: шаги ограничены набором нот (например, пентатоникой) и смещением ±1.

Таким образом, несмотря на случайность, последовательность остаётся гармоничной и музыкальной.

2. Генерация последовательности

const scale = [0,2,4,7,9]; // пентатоника
let seq = [];
let cur = 0;
for(let i=0;i<12;i++){
  const step = (Math.random()*3|0) - 1; // -1,0,+1
  cur = Math.max(0, Math.min(scale.length-1, cur + step));
  seq.push(scale[cur]);
}

Алгоритм: каждый следующий шаг сдвигается на -1, 0 или +1 внутри массива допустимых нот. Результат — «хаотичная», но мелодически осмысленная фраза.

3. Воспроизведение через Web Audio API

Для каждой ноты создаётся осциллятор и небольшой ADSR-огибающийся сигнал. 

const ctx = new (window.AudioContext||window.webkitAudioContext)();
let t = ctx.currentTime;
for(let s of seq){
  const o = ctx.createOscillator();
  const g = ctx.createGain();
  o.type='sine';
  o.frequency.value = 440*Math.pow(2,(60 + s -69)/12);
  o.connect(g);
  g.connect(ctx.destination);
  g.gain.value=0.0001;
  o.start(t);
  g.gain.linearRampToValueAtTime(0.14, t+0.01);
  g.gain.exponentialRampToValueAtTime(0.0001, t+0.22);
  o.stop(t+0.28);
  t += 0.32;
}

Здесь каждая нота «выстреливает» с плавным нарастанием и затуханием — получается музыкальная фраза.

4. Эксперименты с хаосом

Можно менять шаги, длину последовательности, набор нот (например, добавить хроматику). Экспериментируя с ограничениями, вы управляетесь хаосом и получаете уникальные мелодии.
