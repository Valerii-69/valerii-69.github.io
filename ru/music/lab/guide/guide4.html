🫧 Учебник: «Плавающие пузырьки»

1. Что делает визуализация?

Эта страница создаёт анимированный фон, где каждый пузырь — не просто графическая точка, а миниатюрный музыкальный инструмент. Он поднимается вверх, постепенно растворяясь в пространстве, и при своём появлении порождает аккорд.

При активации «медитации» интерфейс исчезает, оставляя только движение и звук. Это режим созерцания — экран становится музыкальной водой, в которой рождаются гармонии.

2. Как рождаются пузырьки

Каждый пузырёк — это объект с координатами x, y, радиусом r, скоростью vy, прозрачностью и цветовым оттенком, зависящим от его частоты. Код создаёт их так: 

function spawn(x, y) {
  const r = 8 + Math.random() * 28;
  const bubble = {
    x: x || Math.random() * W,
    y: y || H + 20,
    r,
    vy: -1 - Math.random() * 2,
    alpha: 0.9,
    hue: 220 + (r / 36) * 100,
    pulse: 0
  };
  bubbles.push(bubble);
  playPolyphonicPhrase(bubble);
}

Чем меньше радиус — тем выше частота и светлее цвет. В результате звук и свет объединяются в одну систему ощущений.

3. Музыкальный синтез пузырей

Для каждого пузыря создаётся три осциллятора (звуковых генератора), образующих аккорд — интервалы 1 : 5/4 : 3/2 соответствуют основному тону, терции и квинте. 

function playPolyphonicPhrase(b) {
  const baseFreq = 65.4;
  const octave = b.r < 18 ? 2 + Math.random() : 1 + Math.random();
  const root = baseFreq * Math.pow(2, octave);
  const intervals = [1, 5/4, 3/2];
  intervals.forEach((ratio, i) => {
    const freq = root * ratio;
    const osc = audioCtx.createOscillator();
    const gain = audioCtx.createGain();
    const pan = audioCtx.createStereoPanner();
    osc.type = ["sine","triangle","sine"][i%3];
    osc.frequency.value = freq;
    pan.pan.value = (b.x / W) * 2 - 1;
    osc.connect(gain).connect(pan).connect(synthMasterGain);
    osc.start();
    osc.stop(audioCtx.currentTime + 2);
  });
}

Так пузырь «поёт» свой короткий аккорд. Панорама зависит от позиции пузыря по оси X — левый пузырь звучит левее, правый — правее.

4. Визуальная алхимия: как рисуется фон

Каждый кадр цикл draw() очищает экран мягким цветом и рисует все пузырьки полупрозрачными градиентами, которые постепенно исчезают. 

function draw() {
  ctx.fillStyle = `hsl(${globalHue}, 40%, 6%)`;
  ctx.fillRect(0, 0, W, H);
  for (let b of bubbles) {
    b.y += b.vy;
    b.alpha *= 0.998;
    const grad = ctx.createRadialGradient(b.x, b.y, 0, b.x, b.y, b.r * 1.6);
    grad.addColorStop(0, `hsla(${b.hue},90%,75%,${b.alpha})`);
    grad.addColorStop(1, `hsla(${b.hue+40},90%,20%,0)`);
    ctx.fillStyle = grad;
    ctx.beginPath();
    ctx.arc(b.x, b.y, b.r, 0, Math.PI * 2);
    ctx.fill();
  }
  requestAnimationFrame(draw);
}

Здесь нет случайных мазков — это визуальная акустика, где каждый пиксель светится в ритме звука.

5. Медитация и управление

Значок ☯ включает режим медитации — интерфейс скрывается, остаётся только движение и звук. Клавиша Esc возвращает элементы управления. Такой подход помогает создать «чистую» атмосферу для наблюдения за музыкальными формами.
