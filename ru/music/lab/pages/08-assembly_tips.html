Советы по монтажу

  • Структура папок: /lab/index.html (главная), /lab/pages/*.html (встроенные страницы), /lab/assets/ (сэмплы, шрифты).
  • Проверяй CORS при попытке загружать локальные файлы через fetch; лучше использовать input type=file для сэмплов.
  • Для мобильных: уменьшай начальный объем звуков и размер холста, используйте requestAnimationFrame экономно.
  • Сохраняй состояние матрицы в sessionStorage или localStorage с версией — это упростит откат.
  • Если нужно делиться страницами — упаковывай выбранный набор страниц в JSON и предлагай «Экспорт».
