Підручник: Пентатонічний сон

Опис синтезатора

Синтезатор створює стерео-тризвучні мелодії на основі пентатонічної шкали. Він використовує назву сну для генерації випадкових, але повторюваних мелодій із заданою базовою нотою, темпом, панорамою, атакою та загасанням. Можна також зберегти сон у WAV.

Елементи інтерфейсу

  • Назва сну: рядок, який визначає унікальну мелодію.
  • Базова нота: вибирається з пентатоніки (C, D, E, G, A).
  • Темп (BPM): швидкість програвання мелодії.
  • Crossfade: плавний перехід між нотами/фразами.
  • Атака/Загасання: регулювання огинаючої кожної ноти.
  • Панорама: положення звуку в стерео (ліва/права сторона).
  • Сгенерувати сон: створює мелодію та візуалізацію на canvas.
  • Записати WAV: зберігає поточний сон у WAV-файлі.
  • Canvas: відображає візуалізацію звукових хвиль з динамічним фоном.
  • Тональність: показує базову ноту та темп.

Принцип роботи

  1. Назва сну перетворюється на числовий seed для повторюваної генерації випадкових чисел.
  2. Визначається октава на основі співвідношення голосних та приголосних.
  3. Створюється масив частот для пентатонічної шкали.
  4. Генерується аудіобуфер із тризвучними фразами з огинаючої атаки та згасання, панорамою та реверберацією.
  5. Аудіобуфер відтворюється через AudioContext, а waveform візуалізується на canvas.
  6. Можна експортувати аудіобуфер до WAV-файлу.

Поради з експериментів

  • Змініть назву сну для створення унікальних мелодій.
  • Експериментуйте з базовою нотою — вона змінює тональність усієї мелодії.
  • Плавно регулюйте атаки та release для більш м'якого або різкого звучання.
  • Використовуйте crossfade для створення плавних переходів між фразами.
  • Панорама дозволяє створювати відчуття руху звуку у просторі.
  • Темп впливає на тривалість фраз та ритміку.
  • Збережіть улюблені мелодії через WAV для подальшого прослуховування або аналізу.

Приклад використання

Введіть назву сну: Нічний вітер, виберіть базову ноту: E, темп 100 BPM. Натисніть Створити сон. Після прослуховування натисніть Записати WAV, щоб зберегти файл.

Основні функції

  • stringToSeed(str): перетворює назву сну в числовий seed для генератора випадкових чисел.
  • seededRandom(seed): повертає функцію повторюваної генерації псевдовипадкових чисел.
  • parseDreamName(name): аналізує назву сну, визначає октаву, реверберацію, довжину фраз та crossfade.
  • noteToFreq(note, octave): перетворює ноту та октаву на частоту.
  • generateDreamAudio(params): створює аудіобуфер із тризвучними фразами.
  • playDream(buffer): відтворює аудіобуфер із візуалізацією на canvas.
  • exportWav(buffer): зберігає поточний сон у WAV-файл.
