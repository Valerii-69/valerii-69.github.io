Підручник: Генератор пентатонічних снів

Опис синтезатора

Синтезатор 7 створює кілька пентатонічних снів, поєднує їх з кросфейдом, додає реверберацію та візуалізує результат на canvas. Кожне відтворення створює унікальну комбінацію звуків, які можна зберегти у WAV.

Елементи інтерфейсу

  • Кількість снів: кількість окремих мелодій, які будуть об'єднані.
  • Тривалість сну (сек): тривалість кожної мелодії.
  • Сила ревербу: інтенсивність ефекту реверберації.
  • Швидкість кросфейду (сек): плавність переходу між мелодіями.
  • Сгенерувати та програти: створює комбіновану мелодію, візуалізує її та програє.
  • Canvas: відображає візуалізацію звукових хвиль.
  • Завантажити WAV: з'являється посилання для збереження комбінованого сну.

Принцип роботи

  1. Генеруються випадкові базові частоти для кожної мелодії.
  2. Вибирається випадкова пентатонічна шкала для кожного сну.
  3. Створюється аудіобуфер із синусоїдними хвилями.
  4. Застосовується реверберація для глибини звуку.
  5. Мелодії поєднуються із заданим crossfade.
  6. Візуалізація здійснюється на canvas.
  7. Відтворюється через AudioContext і надається посилання для завантаження WAV.

Поради з експериментів

  • Збільште кількість снів для більш складної текстури мелодії.
  • Змініть тривалість сну для коротких або довгих фраз.
  • Використовуйте реверберацію для створення простору та атмосфери.
  • Спробуйте різні значення crossfade для більш плавного або різкого з'єднання мелодій.
  • Кожен відтворення створює унікальний сон завдяки випадковим базовим частотам та вибору шкали.

Приклад використання

Встановіть число снів = 5, тривалість сну = 3 сек, реверб = 0.3, кросфейд = 0.5. Натисніть 🎧 Згенерувати та програти. Після прослуховування з'явиться посилання 💾 Завантажити WAV.

Основні функції синтезатора

  • generateDream(freqBase, scale, duration): створює одну пентатонічну мелодію.
  • addReverb(signal, amount): застосовує просту реверберацію.
  • mergeDreams(dreams, crossfadeTime): поєднує кілька мелодій з кросфейдом.
  • visualize(canvas, buffer): відображає амплітуду звуку на canvas.
  • encodeWAV(samples, sampleRate): перетворює аудіобуфер на WAV для скачування.
