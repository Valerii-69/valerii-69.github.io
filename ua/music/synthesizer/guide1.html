Підручник - Синтезатор «Музичний лабіринт» (guide1)

Коротко: цей синтезатор — сітка 7×7 осередків, кожен осередок несе свою групу гармонік. При торканні (або кліку) осередку або програється семпл, або генерується комбінація осциляторів (режим synth). Є транспозер, регулювання загасання та кількість повторів (стак ефектів).

Що ви почуєте

  • У режимі synth — багате «пилкоподібне» звучання (sawtooth), де кожен осередок запускає набір гармонік.
  • У режимі sample — завантажені вами аудіофайли відтворюються з накладанням повторів та плавним спадом гучності.
  • Транспозиція (transpose) зрушує всі активні ноти в реальному часі – можна отримати ефект хорового зміщення.
  • Параметри repeats та release керують щільністю шарів і довжиною згасання відповідно.

Що можна налаштувати та досліджувати

Практичні ідеї:
  • Збільште repeats і зменшіть release — отримайте звукову стяжку, як ритмічний патерн.
  • Поставте mode у sample і завантажте короткі ударні семпли — сітка перетвориться на драм-машину.
  • Експериментуйте з транспозером: плавний рух слайдера створює глісандо у всіх активних осциляторів.
  • Змініть форму осцилятора (sine/square/triangle) у коді playSynth — тембр різко зміниться.

Ключові моменти в коді (готове до копіювання)

1) Ініціалізація AudioContext та базові структури

// створюємо AudioContext та сховища
let audioCtx = new (window.AudioContext || window.webkitAudioContext)();
const size = 7;
const cells = [];
const cellHarmonics = new Map();
let buffers = []; // Array<AudioBuffer> для режиму sample
let activeOscillators = new Map(); // відстежуємо запущені осцилятори

2) Створення сітки 7×7 (DOM)

// додаємо комірки в контейнер gridEl
for (let y = 0; y < size; y++) { 
for (let x = 0; x < size; x++) { 
const cell = document.createElement('span'); 
cell.className = 'cell'; 
cell.dataset.x = x; 
cell.dataset.y = y; 
gridEl.appendChild(cell); 
cells.push(cell); 
// cellHarmonics.set(cell, [...]) - задаємо пізніше 
}
}

3) Відтворення синтезу (playSynth)

function playSynth(idx, cell) { 
const repeat = Number(repeatsSlider.value) || 1; 
const release = Number(releaseSlider.value) || 20; 
const trans = Number(transposeSlider.value) || 0; 
const baseFreq = 261.63; // C4 
const harmonics = cellHarmonics.get(cell) || [1]; 

harmonics.forEach(mult => { 
for (let i = 0; i < repeat; i++) { 
const osc = audioCtx.createOscillator(); 
osc.type = 'sawtooth'; // спробуйте 'sine', 'square', 'triangle' 
const freq = baseFreq * mult * Math.pow (2, (idx + trans) / 12); 
osc.frequency.value = freq; 

const gain = audioCtx.createGain(); 
gain.gain.setValueAtTime(0.5 / repeat, audioCtx.currentTime + i * 0.05); 
gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + i * 0.05 + release * 0.05); 

osc.connect(gain).connect(audioCtx.destination); 
osc.start(audioCtx.currentTime + i * 0.05); 
osc.stop(audioCtx.currentTime + i * 0.05 + release * 0.05); 

activeOscillators.set(osc, {idx, gain}); 
osc.onended = () = gt; activeOscillators.delete(osc); 
} 
});
}

4) Відтворення семплів (playSample)

async function playSample(idx) { 
if (!buffers.length) return; 
const repeat = Number(repeatsSlider.value) || 1; 
const release = Number(releaseSlider.value) || 20; 
const buffer = buffers[idx % buffers.length]; 

for (let i = 0; i < repeat; i++) { 
const src = audioCtx.createBufferSource(); 
src.buffer = buffer; 
const gain = audioCtx.createGain(); 
gain.gain.setValueAtTime(1, audioCtx.currentTime + i * 0.05); 
gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + i * 0.05 + release * 0.05); 
src.connect(gain).connect(audioCtx.destination); 
src.start(audioCtx.currentTime + i * 0.05); 
}
}

5) Завантаження файлів у buffers (input[type=file])

sampleInput.addEventListener('change', async(e) => { 
const files = Array.from(e.target.files); 
buffers = []; 
for (let f of files) { 
const ab = await f.arrayBuffer(); 
const buf = await audioCtx.decodeAudioData(ab); 
buffers.push(buf); 
} 
sampleStatus.textContent = `${buffers.length} файлів`;
});

6) Транспозиція у реальному часі

transposeSlider.addEventListener('input', () => { 
transposeValue.textContent = transposeSlider.value; 
const trans = Number(transposeSlider.value); 
//Змінюємо частоту всіх активних осциляторів 
activeOscillators.forEach(({ idx }, osc) => { 
const freq = 261.63 * Math.pow (2, (idx + trans) / 12); 
osc.frequency.setValueAtTime(freq, audioCtx.currentTime); 
});
});

Рекомендації та поради

  • Якщо браузер блокує звук — викличте audioCtx.resume() у відповідь на клік/торкання користувача.
  • Для меншого завантаження CPU замініть фрактальну візуалізацію на простий canvas-паттерн або відключіть її зовсім.
  • Щоб керувати тоном музичніше, зберігайте для кожного осередку не індекс idx, а заздалегідь обчислені частоти (у герцах).
  • Додайте BiquadFilterNode перед виходом у destination, щоб пом'якшувати високий спектр sawtooth.

Короткий чек-лист для тестування

  • Натисніть New — сітка отримала гармоніки (кольори також).
  • Натисніть на комірку в режимі synth — має пролунати тон.
  • Перемкніть у sample, завантажте хоча б один файл — при дотику повинен грати запис.
  • Покрутіть транспозер — активні осцилятори змінюють висоту.
  • Натисніть Stop — усі осцилятори повинні зупинитися.
