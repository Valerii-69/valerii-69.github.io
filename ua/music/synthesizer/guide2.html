🎧 Guide 2 — Ноти та ADSR

Що робить цей синтезатор

Цей синтезатор дозволяє почути, як із простої форми хвилі народжується нота з динамічною огинаючою. При кожному натисканні кнопки «Програти ноту» генерується вибрана частота (наприклад, A4 = 440 Гц) і формується звукова хвиля заданого типу - синус, квадрат, пилка, трикутник або трапеція.

Основна ідея – дослідити, як параметри ADSR (Attack, Decay, Sustain, Release) формують характер звучання. Це модель розвитку гучності у часі: від м'якого початку до згасання після відпускання ноти.

Що можна почути та налаштувати

Виберіть ноту (A2–A5), змінюйте тип хвилі та параметри ADSR. Спробуйте короткий Attack і довгий Release звук стане більш «співучим». Збільште Decay та зменшіть Sustain — отримайте характерний "удар" клавішного інструменту.

4. Відображення огинаючої ADSR


function drawEnvelope(a, d, s, r) { 
const width=envCanvas.width; 
const height = envCanvas.height; 
const total = a + d + r + 0.2; 

ectx.beginPath(); 
ectx.moveTo(0, height); 
ectx.lineTo(width*(a/total), 0); 
ectx.lineTo(width*((a+d)/total), height*(1 - s)); 
ectx.lineTo(width*((a+d+0.2)/total), height*(1 - s)); 
ectx.lineTo(width, height); 
ectx.stroke();
}

Підсумок

Цей синтезатор є простою лабораторією для вивчення динаміки звуку. Тут можна спостерігати, як геометрія форми хвилі поєднується з часовою структурою ADSR. Ідеально підходить для експериментів із сприйняттям атаки, згасання та післязвучання.
