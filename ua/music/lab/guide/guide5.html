🎧 Підручник: «Семпли - Завантаження локально»

1. Призначення експерименту

Ця лабораторна сторінка дозволяє підвантажувати власні аудіофайли прямо з пристрою. чи це окремі звуки, семпли або цілі колекції з папки /samples.

Браузер не має доступу до файлової системи безпосередньо: ви дозволяєте читати тільки файли, які виберете вручну через <input type="file">. Це обмеження вбудоване в систему безпеки, щоб веб-сторінки не могли заглядати в особисті каталоги.

2. Як працює завантаження

Після вибору файлів елемент input передає масив FileList. Код обходить його, створює візуальний список та кнопку "Play" для кожного файлу. 

fileEl.addEventListener('change', async(e) => { 
const files = Array.from(e.target.files); 
list.innerHTML = ''; 
for (const f of files) { 
const el = document.createElement('div'); 
el.className = 'sample'; 
el.textContent = f.name; 
const play = document.createElement('button'); 
play.textContent = 'Play'; 
el.appendChild(play); 
list.appendChild(el); 
}
});

Так створюється динамічна галерея маленький каталог ваших звуків.

3. Відтворення через Web Audio API

Для кожного файлу при натисканні кнопки створюється об'єкт AudioContext, в якому звук декодується та програється як буфер. 

play.addEventListener('click', async() => { 
if (!ctx) ctx = new (window.AudioContext || window.webkitAudioContext)(); 
const arr = await f.arrayBuffer(); 
const buf = await ctx.decodeAudioData(arr.slice(0)); 
const s = ctx.createBufferSource(); 
s.buffer = buf; 
s.connect(ctx.destination); 
s.start();
});

Тут браузер перетворює байти файлу на цифрову хвилю. Звук не стримується, а завантажується повністю, щоб програвач міг точно контролювати його початок та кінець.

4. Можливості розширення

- Додай візуалізацію частот за допомогою AnalyserNode - вийде живий спектр. — Або задай кожному семплу власну гучність, панораму, фільтр. — Можна об'єднувати кілька буферів в один мікс та будувати багатошарові колажі.

Так просте завантаження перетворюється на перший крок до власної цифрової студії.

5. Чому «локально»?

Тому що це нагадує старі аналогові експерименти: все поряд, під рукою. Звук стає особистим матеріалом, а не завантаженим із хмари. Кожен WAV це фрагмент пам'яті, і лабораторія дає можливість слухати їх як частини акустичної біографії.
