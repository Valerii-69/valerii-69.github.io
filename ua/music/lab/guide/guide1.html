«Інтро: Подорож Лабораторією»

Цей навчальний модуль пояснює, як працює перша сторінка Лабораторії. Тут ви познайомитеся з основами Web Audio API і створите своє перше «коло», що «звучить».

1. Ідея експерименту

Головна мета інтро — показати, що кожен осередок Лабораторії може оживати, перетворюючись на музичний елемент. Вся магія будується на трьох речах:

  • AudioContext — створює звуковий простір браузера;
  • OscillatorNode — генерує звук певної частоти;
  • ConvolverNode — створює ефект відлуння або реверберації.

2. Ключовий фрагмент коду

const ctx = new (window.AudioContext || window.webkitAudioContext)();
const osc = ctx.createOscillator();
const gain = ctx.createGain();
const reverb = ctx.createConvolver();

// створюємо коротку "імпульсну характеристику" - луна
const len ​​= ctx.sampleRate * 1.2;
const impulse = ctx.createBuffer(2, len, ctx.sampleRate);
for (let ch = 0; ch < 2; ch++) { 
const data = impulse.getChannelData(ch); 
for (let i = 0; i < len; i++) { 
data[i] = (Math.random() * 2 - 1) * Math.pow(1 - i / len, 2.5); 
}
}
reverb.buffer = impulse;

// Підключаємо вузли
osc.connect(gain);
gain.connect(reverb);
reverb.connect(ctx.destination);
Тут створюється проста модель "залу", де звук поступово згасає. При кожному натисканні частота трохи змінюється — начебто ви робите крок новою кімнатою лабіринту.

3. Спробуйте самі

Натисніть на гурток нижче — він згенерує випадковий тон та м'яку луну. Цей код використовує той самий принцип, що й оригінальна сторінка Інтро.

Натиснути

4. Що відбувається під капотом

Кожен раз, коли ви натискаєте кнопку, скрипт:

  1. створює новий AudioContext,
  2. вибирає випадкову ноту поряд з ля (A4 = 440 Гц),
  3. плавно збільшує гучність, а потім зменшує її,
  4. додає легкий реверб, щоб звук “жив” трохи довше.

5. Експеримент для читача

Спробуйте змінити параметри коду: freq = baseFreq * Math.pow(2, randSemitone / 12) - Це формула, що переводить інтервали в герці. Якщо замінити 12 на 24, крок між тонами стане вдвічі меншим, і звуки будуть ближче один до одного.
