🎶 Підручник: «Генератор - Хаос та мелодія»

1. Ідея генератора

Цей генератор створює короткі мелодійні фрази, де хаотична випадковість підпорядковується простому правилу: кроки обмежені набором нот (наприклад, пентатонікою) та усуненням ±1.

Таким чином, незважаючи на випадковість, послідовність залишається гармонійною та музичною.

2. Генерація послідовності

const scale = [0,2,4,7,9]; // Пентатоніка
let seq = [];
let cur = 0;
for(let i=0;i<12;i++){ 
const step = (Math.random()*3|0) - 1; //-1,0, +1 
cur = Math.max(0, Math.min(scale.length-1, cur + step)); 
seq.push(scale[cur]);
}

Алгоритм: кожен наступний крок зсувається на -1, 0 або +1 усередині масиву допустимих нот. Результат — хаотична, але мелодійно осмислена фраза.

3. Відтворення через Web Audio API

Для кожної ноти створюється осцилятор і невеликий ADSR-огинальний сигнал. 

const ctx = new (window.AudioContext||window.webkitAudioContext)();
let t = ctx.currentTime;
for(let s of seq) { 
const o = ctx.createOscillator(); 
const g = ctx.createGain(); 
o.type='sine'; 
o.frequency.value = 440*Math.pow(2,(60 + s -69)/12); 
o.connect(g); 
g.connect(ctx.destination); 
g.gain.value=0.0001; 
o.start(t); 
g.gain.linearRampToValueAtTime(0.14, t+0.01); 
g.gain.exponentialRampToValueAtTime(0.0001, t+0.22); 
o.stop(t+0.28); 
t += 0.32;
}

Тут кожна нота «вистрілює» з плавним наростанням і згасанням — виходить музична фраза.

4. Експерименти з хаосом

Можна змінювати кроки, довжину послідовності, набір нот (наприклад, додати хроматику). Експериментуючи з обмеженнями, ви керуєтеся хаосом та отримуєте унікальні мелодії.
