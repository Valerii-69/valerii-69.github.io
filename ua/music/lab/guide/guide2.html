Підручник: Пентатонічна лабораторія

Мета експерименту

Лабораторія дозволяє досліджувати звучання пентатонічної гами — набору п'яти звуків, утворюють гармонійні співзвуччя без напівтонів. Тут можна керувати тембром, інтервалами, поліфонією та спостерігати живу осцилограму звуку.

Основні модулі

1. Matrix (нотова матриця)

Генерує пентатонічний ряд обраної базової ноти. Кнопки нот активують відповідні частоти, побудовані за обраною моделлю (12-TET, піфагорійська і т.д.).

2. AudioEngine

Використовує AudioContext та осцилятори Web Audio API. Кожен голос створюється з параметрами osc.type (хвиля) та gain (гучність). Звук обробляється через AnalyserNode та реверберацію.

3. Transposer

Відповідає за інтервали та поліфонію — додавання терцій, квінт, тризвучій та їхнє розщеплення на кілька голосів. Використовуються інтервальні пресети: {note:[0], third:[0,4], fifth:[0,7], triad:[0,4,7]}.

4. Oscilloscope

Реалізовано через Canvas. Відображає осцилограму в реальному часі, використовуючи дані з AnalyserNode.getByteTimeDomainData(). Лінія візуалізується градієнтом - фіолетовий, бірюзовий, бузковий.

Математичні моделі частот

Вибір математичної моделі дозволяє порівняти різні музичні лади.

  • 12-TET — рівномірна темперація, стандарт для фортепіано та синтезаторів.
  • Піфагорійська — інтервали будуються на чистих квінтах 3:2.
  • Чиста інтонація — частоти виражаються простими дробами m/n.
  • Гармонічний ряд — кожен звук = k-а гармоніка базової частоти.

Приклад формули для 12-TET: f = f0 * 2^((n - n0)/12)

Інтерактивний приклад

Спробуй змінити базову ноту та натиснути кнопку «Програти ряд». Осцилограма зміниться в реальному часі.


// Приклад коду програвання ряду
function playRowSequential() { 
const pent = generatePentSet(currentBaseIndex); 
let t = 0; 
for (const n of pent) { 
setTimeout(() => playChord([n]), t * 1000); 
t += 0.5; 
   
}
}

Як працює поліфонія

Для кожного нота створюються кілька осциляторів, трохи засмучених між собою (на ±6 центів) і панорамовані ліворуч і праворуч. Це створює ефект просторового звучання.

Поради для експериментів

  • Слухай через навушники – так краще відчувається просторова панорама.
  • Спробуй чергувати хвилі: triangle для м'якості, sawtooth для насиченості.
  • Порівняй гармонійний ряд з рівномірною темперацією та відчуй різницю.
