🫧 Підручник: «Плаваючі бульбашки»

1. Що робить візуалізація?

Ця сторінка створює анімований фон, де кожен міхур - не просто графічна точка, а мініатюрний музичний інструмент. Він піднімається вгору, поступово розчиняючись у просторі, і за своєю появою породжує акорд.

При активації медитації інтерфейс зникає, залишаючи тільки рух і звук. Це режим споглядання – екран стає музичною водою, у якій народжуються гармонії.

2. Як народжуються бульбашки

Кожна бульбашка - це об'єкт з координатами x, y, радіусом r, швидкістю vy, прозорістю та колірним відтінком, що залежить від його частоти. Код створює їх так: 

function spawn(x, y) { 
const r = 8 + Math.random() * 28; 
const bubble = { 
x: x || Math.random() * W, 
y: y || H + 20, 
r, 
vy: -1 - Math.random() * 2, 
alpha: 0.9, 
hue: 220 + (r / 36) * 100, 
pulse: 0 
}; 
bubbles.push(bubble); 
playPolyphonicPhrase(bubble);
}

Чим менший радіус — тим вища частота і світліший колір. В результаті звук і світло поєднуються в одну систему відчуттів.

3. Музичний синтез бульбашок

Для кожного міхура створюється три осцилятори (звукові генератори), що утворюють акорд. інтервали 1: 5/4: 3/2 відповідають основному тону, терції та квінті. 

function playPolyphonicPhrase(b) { 
const baseFreq = 65.4; 
const octave = b.r < 18? 2 + Math.random() : 1 + Math.random(); 
const root = baseFreq * Math.pow (2, octave); 
const intervals = [1, 5/4, 3/2]; 
intervals.forEach((ratio, i) => { 
const freq = root * ratio; 
const osc = audioCtx.createOscillator(); 
const gain = audioCtx.createGain(); 
const pan = audioCtx.createStereoPanner(); 
osc.type = ["sine","triangle","sine"][i%3]; 
osc.frequency.value = freq; 
pan.pan.value = (b.x / W) * 2 - 1; 
osc.connect(gain).connect(pan).connect(synthMasterGain); 
osc.start(); 
osc.stop(audioCtx.currentTime + 2); 
});
}

Так міхур «співає» свій короткий акорд. Панорама залежить від позиції міхура по осі X — лівий міхур звучить лівіше, правий - правіше.

4. Візуальна алхімія: як малюється тло

Кожен кадр цикл draw() очищає екран м'яким кольором і малює всі бульбашки напівпрозорими градієнтами, що поступово зникають. 

function draw() { 
ctx.fillStyle = `hsl(${globalHue}, 40%, 6%)`; 
ctx.fillRect(0, 0, W, H); 
for (let b of bubbles) { 
b.y + = b.vy; 
b.alpha *= 0.998; 
const grad = ctx.createRadialGradient(b.x, b.y, 0, b.x, b.y, b.r * 1.6); 
grad.addColorStop(0, `hsla(${b.hue},90%,75%,${b.alpha})`); 
grad.addColorStop(1, `hsla(${b.hue+40},90%,20%,0)`); 
ctx.fillStyle = grad; 
ctx.beginPath(); 
ctx.arc(b.x, b.y, b.r, 0, Math.PI * 2); 
ctx.fill(); 
} 
requestAnimationFrame(draw);
}

Тут немає випадкових мазків – це візуальна акустика, де кожен піксель світиться у ритмі звуку.

5. Медитація та управління

Значок ☯ включає режим медитації - інтерфейс приховується, залишається лише рух та звук. Клавіша Esc повертає елементи керування. Такий підхід допомагає створити чисту атмосферу для спостереження за музичними формами.
