🧭 Гід JavaScript — Лабораторія читача

1. Змінні та типи даних

У JavaScript можна зберігати дані різних типів: числа, рядки, логічні значення, об'єкти та багато іншого.

// Приклади змінних
let ім'я = "Валерій";
let вік = 72;
let активний = true;

console.log("Привіт", ім'я);
console.log("Вік:", вік);

Для оголошення змінних використовуються let та const. Різниця в тому, що const не можна змінити.

2. Функції та взаємодія

Функції дозволяють збирати логіку у зручні блоки коду. Наприклад, створимо просту функцію привітання:

function привітання(ім'я) { 
return "Привіт, "+ ім'я +"!";
}

console.log(вітання("читач"));

Функції можна передавати як значення, зберігати в змінних і навіть повертати з інших функцій — це дає неймовірну гнучкість.

3. Маніпуляції з HTML

JavaScript може змінювати вміст сторінки на льоту. Ось приклад динамічної зміни тексту:

<button onclick="змінитиТекст()">Натисніть мене</button>
<p id="demo">Привіт!</p>

<script>
function змінитиТекст() { 
document.getElementById("demo").innerText = "Ти змінив текст!";
}
</script>

Так можна створювати інтерактивні елементи прямо всередині сторінки лабораторії.
