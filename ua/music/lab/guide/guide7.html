1. Ідея генератора

Ми створюємо просту мелодійну ідею, що базується на детермінованій випадковості. Це означає, що одна й та сама тема дає той самий результат, ніби у нас «ІІ з пам'яттю».

2. Перетворення тексту на число

УВАГА ДОВІДКА: Щоб браузер не зіпсував код (переплутавши кутові дужки з HTML-тегами), ми екрануємо символи <, > та &. Потім бібліотека highlight.js розфарбовує синтаксис. Це і є безпечне виведення коду. 

 
<!-- Підключаємо стилі та двигун підсвічування highlight.js -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.9.0/styles/github-dark.min.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.9.0/highlight.min.js"></script>
<script>hljs.highlightAll();</script> 



function hashSeed(s) { 
let h = 0; 
for (let i = 0; i < s.length; i++) { 
h = (h * 31 + s.charCodeAt(i)) | 0; 
} 
return Math.abs(h);
}

Кожен символ тексту впливає на число seed, що задає послідовність «випадкових» чисел.

3. Генерація мелодії


const base = 60 + (seed % 12); // Базова нота
const scale = [0, 2, 3, 5, 7, 9, 10]; //діатоніка
const seq = [];

for (let i = 0; i < 8; i++) { 
const r = Math.floor(rng() * scale.length); 
seq.push(scale[r]);
}

Масив інтервалів scale задає структуру ладів, а генератор rng() вибирає випадкові ноти щодо базової. Результат буде однаковий за однакового seed.

4. Емуляція ІІ через детерміновану випадковість

Ми не використовуємо нейромережі, але відтворюємо ілюзію розуму за рахунок передбачуваної випадковості. Алгоритм лінійної конгруенції (LCG) генерує однакові послідовності при тому самому seed.
