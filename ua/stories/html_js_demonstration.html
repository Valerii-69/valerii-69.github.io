HTML+JS Демонстрація

Нижче наведено інтерактивний блок, де при кліку генерується випадкове число. Це проста демонстрація динамічної взаємодії з користувачем за допомогою JavaScript.

Натисни мене

// Отримуємо посилання на елементи сторінки
const demoBox = document.getElementById('demoBox');
const resetBtn = document.getElementById('resetBtn');

// Функція для генерації випадкового числа від 1 до 100
function randomNumber() {
  return Math.floor(Math.random() * 100) + 1;
}

// Обробник кліку по блоку
demoBox.addEventListener('click', () => {
  demoBox.textContent = randomNumber();
});

// Обробник кліку по кнопці скидання
resetBtn.addEventListener('click', () => {
  demoBox.textContent = 'Натисни мене';
});

// Доступність через клавіатуру (Enter або Пробіл)
demoBox.addEventListener('keydown', (event) => {
  if(event.key === 'Enter' || event.key === ' ') {
    event.preventDefault();
    demoBox.textContent = randomNumber();
  }
});
Пояснення коду:
  • getElementById — шукає елемент за ID на сторінці.
  • Math.random() генерує число від 0 до 1 (не включаючи 1).
  • Math.floor() округлює вниз до цілого числа.
  • Обробники подій click та keydown запускають функції при кліку чи натисканні клавіш.
  • Атрибути tabindex та role="button" роблять блок доступним для навігації клавіатурою.
  • event.preventDefault() відміняє стандартну поведінку браузера (наприклад, прокрутку при пробілі).
