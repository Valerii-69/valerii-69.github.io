Лабораторна робота — перевірка JS-коду

Інструкція для читача:

  • Використовуйте лише наданий canvas, не звертайтеся до document.getElementById.
  • Ваш код повинен бути функцією, що приймає canvas:
    • (function(canvas){ /* ваш код */ })(canvas);
  • Усі змінні повинні бути локальними, анімації — через requestAnimationFrame або setInterval.

Приклад робочого коду:

(function(canvas){
  const ctx = canvas.getContext('2d');
  let x = 0;
  function animate(){
    ctx.clearRect(0,0,canvas.width,canvas.height);
    ctx.fillStyle='red';
    ctx.fillRect(x,50,50,30);
    x = (x + 2) % canvas.width;
    requestAnimationFrame(animate);
  }
  animate();
})(canvas);
