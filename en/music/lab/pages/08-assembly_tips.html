Editing Tips

  • Folder structure: /lab/index.html (main), /lab/pages/*.html (embedded pages), /lab/assets/ (samples, fonts).
  • Check CORS when attempting to load local files via fetch; it's best to use input type=file for samples.
  • For mobile: reduce the initial sound volume and canvas size, use requestAnimationFrame sparingly.
  • Save the matrix state in sessionStorage or localStorage with the version – this will simplify rollback.
  • If you need to share pages, package the selected set of pages in JSON and offer "Export."
