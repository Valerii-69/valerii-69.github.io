"Intro: A Journey Through the Lab"

This tutorial explains how the first page of the Lab works. Here you'll learn the basics of the Web Audio API and create your first "sounding circle."

1. Experiment Idea

The main goal of the intro is to show that each cell in the Lab can come to life, turning into a musical element. All the magic is built on three things:

  • AudioContext — creates the browser's sound space;
  • OscillatorNode — generates sound of a specific frequency;
  • ConvolverNode — creates an echo or reverberation effect.

2. Key Code Snippet

const ctx = new (window.AudioContext || window.webkitAudioContext)();
const osc = ctx.createOscillator();
const gain = ctx.createGain();
const reverb = ctx.createConvolver();

// создаём короткую "импульсную характеристику" — эхо
const len = ctx.sampleRate * 1.2;
const impulse = ctx.createBuffer(2, len, ctx.sampleRate);
for (let ch = 0; ch < 2; ch++) {
  const data = impulse.getChannelData(ch);
  for (let i = 0; i < len; i++) {
    data[i] = (Math.random() * 2 - 1) * Math.pow(1 - i / len, 2.5);
  }
}
reverb.buffer = impulse;

// подключаем узлы
osc.connect(gain);
gain.connect(reverb);
reverb.connect(ctx.destination);
Here we create a simple "hall" model where the sound gradually fades out. Each click changes the frequency slightly—as if you were taking a step into a new room of a maze.

4. What's going on under the hood?

Every time you press a button, the script:

  1. creates a new AudioContext,
  2. chooses a random note near A (A4 = 440 Hz),
  3. gradually increases the volume, then decreases it,
  4. adds a slight reverb to make the sound last a little longer.

5. An Experiment for the Reader

Try changing the parameters in the code: freq = baseFreq * Math.pow(2, randSemitone / 12) — this is the formula that converts intervals to hertz. If you replace 12 with 24, the pitch between tones will be halved, and the sounds will be closer together.
