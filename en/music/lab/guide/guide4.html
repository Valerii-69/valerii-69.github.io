🫧 Tutorial: "Floating Bubbles"

1. What does visualization do?

This page creates an animated background where each bubble is not just a graphic dot, but a miniature musical instrument. It rises, gradually dissolving into space, and upon its appearance, it plays a chord.

When "meditation" is activated, the interface disappears, leaving only movement and sound. This is contemplation mode—the screen becomes musical water in which harmonies are born.

2. How bubbles are born

Each bubble is an object with coordinates x, y, radius r, speed vy, opacity, and a color tint based on its frequency. The code creates them like this: 

function spawn(x, y) {
const r = 8 + Math.random() * 28;
const bubble = {
x: x || Math.random() * W,
y: y || H + 20,
r,
vy: -1 - Math.random() * 2,
alpha: 0.9,
hue: 220 + (r / 36) * 100,
pulse: 0
};
bubbles.push(bubble);
playPolyphonicPhrase(bubble);
}

The smaller the radius, the higher the frequency and the brighter the color. As a result, sound and light are combined into a single sensory system.

3. Musical synthesis of bubbles

For each bubble, three oscillators (sound generators) are created, forming a chord - the intervals 1:5/4:3/2 correspond to the root note, third, and fifth. 

function playPolyphonicPhrase(b) {
const baseFreq = 65.4;
const octave = b.r < 18 ? 2 + Math.random() : 1 + Math.random();
const root = baseFreq * Math.pow(2, octave);
const intervals = [1, 5/4, 3/2]; 
intervals.forEach((ratio, i) => { 
const freq = root * ratio; 
const osc = audioCtx.createOscillator(); 
const gain = audioCtx.createGain(); 
const pan = audioCtx.createStereoPanner(); 
osc.type = ["sine","triangle","sine"][i%3]; 
osc.frequency.value = freq; 
pan.pan.value = (b.x / W) * 2 - 1; 
osc.connect(gain).connect(pan).connect(synthMasterGain); 
osc.start(); 
osc.stop(audioCtx.currentTime + 2); 
});
}

This is how the bubble “sings” its short chord. The panorama depends on the bubble's position on the X axis — the left bubble sounds to the left, the right bubble sounds to the right.

4. Visual Alchemy: How the Background Is Drawn

Each frame, the draw() loop clears the screen with a soft color and draws all the bubbles with translucent gradients that gradually fade in. 

function draw() {
ctx.fillStyle = `hsl(${globalHue}, 40%, 6%)`;
ctx.fillRect(0, 0, W, H);
for (let b of bubbles) {
b.y += b.vy;
b.alpha *= 0.998;
const grad = ctx.createRadialGradient(b.x, b.y, 0, b.x, b.y, b.r * 1.6); 
grad.addColorStop(0, `hsla(${b.hue},90%,75%,${b.alpha})`); 
grad.addColorStop(1, `hsla(${b.hue+40},90%,20%,0)`); 
ctx.fillStyle = grad; 
ctx.beginPath(); 
ctx.arc(b.x, b.y, b.r, 0, Math.PI * 2); 
ctx.fill(); 
} 
requestAnimationFrame(draw);
}

There are no random brushstrokes here—this is visual acoustics, where every pixel glows in time with the sound.

5. Meditation and Controls

The ☯ icon activates meditation mode—the interface is hidden, leaving only movement and sound. The Esc key returns the controls. This approach helps create a "clean" atmosphere for observing musical forms.
