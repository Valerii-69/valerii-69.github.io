We're creating a simple melodic idea based on deterministic randomness. This means that the same theme produces the same result, as if we had "AI with memory."

function hashSeed(s) { 
let h = 0; 
for (let i = 0; i < s.length; i++) {
h = (h * 31 + s.charCodeAt(i)) | 0;
}
return Math.abs(h);
}

Each character of the text affects a number — seed, which defines a sequence of "random" numbers.

3. Melody Generation


const base = 60 + (seed % 12); // base note
const scale = [0, 2, 3, 5, 7, 9, 10]; // diatonic
const seq = [];

for (let i = 0; i < 8; i++) {
const r = Math.floor(rng() * scale.length);
seq.push(scale[r]);
}

The interval array scale defines the scale structure, and the generator rng() selects random notes relative to the base note. The result will be the same with the same seed.

4. Emulating AI through Deterministic Randomness

We don't use neural networks, but we reproduce the illusion of "intelligence" through predictable randomness. The Linear Congruence Group (LCG) algorithm generates identical sequences with the same seed.
