Textbook: Pentatonic Lab

Purpose of the Experiment

The Lab allows you to explore the sound of the pentatonic scale — a set of five notes that form harmonic harmonies without semitones. Here you can control the timbre, intervals, and polyphony, and view a live oscillogram of the sound.

Main Modules

1. Matrix

Generates a pentatonic scale from a selected base note. The note buttons activate the corresponding frequencies, built according to the selected model (12-TET, Pythagorean, etc.).

2. AudioEngine

Uses AudioContext and Web Audio API oscillators. Each voice is created with osc.type (waveform) and gain (volume) parameters. Audio is processed via AnalyserNode and reverb.

3. Transposer

Responsible for intervals and polyphony – adding thirds, fifths, triads, and splitting them into multiple voices. The following interval presets are used: {note:[0], third:[0.4], fifth:[0.7], triad:[0.4.7]}.

4. Oscilloscope

Implemented via Canvas. Displays a real-time waveform using data from AnalyserNode.getByteTimeDomainData(). The line is visualized with a gradient—purple, turquoise, and lilac.

Mathematical Frequency Models

Choosing a mathematical model allows you to compare different musical scales.

  • 12-TET — equal temperament, the standard for pianos and synthesizers.
  • Pythagorean — intervals are built on perfect fifths 3:2.
  • Pure intonation — frequencies are expressed as simple fractions m/n.
  • Harmonic series — each note = the k-th harmonic of the base frequency.

Example formula for 12-TET: f = f0 * 2^((n - n0)/12)

Interactive example

Try changing the base note and click "Play series." The oscilloscope will change in real time.


// Example code for playing a sequence
function playRowSequential() {
const pent = generatePentSet(currentBaseIndex);
let t = 0;
for (const n of pent) {
setTimeout(() => playChord([n]), t * 1000);
t += 0.5;
}
}

How Polyphony Works

For each note, several oscillators are created, slightly detuned from each other (by ±6 cents) and panned left and right. This creates a spatial sound effect.

Tips for Experimentation

  • Listen through headphones – it will better convey the spatial panorama.
  • Try alternating waves: triangle for softness, sawtooth for richness.
  • Compare the harmonic series with equal temperament and feel the difference.
