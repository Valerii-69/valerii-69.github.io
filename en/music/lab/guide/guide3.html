1. Variables and Data Types

JavaScript allows you to store different types of data: numbers, strings, Booleans, objects, and more.

// Variable Examples
let name = "Valery";
let age = 72;
let active = true;

console.log("Hello," name);
console.log("Age:," age);

Variables are declared using let and const. The difference is that const cannot be modified.

2. Functions and Interaction

Functions allow you to compose logic into convenient blocks of code. For example, let's create a simple greeting function:

function greeting(name) {
return "Hello, " + name + "!";
}

console.log(greeting("reader"));

Functions can be passed as values, stored in variables, and even returned from other functions—this gives incredible flexibility.

3. HTML Manipulation

JavaScript can change page content on the fly. Here's an example of dynamic text change:

<button onclick="changeText()">Click me</button>
<p id="demo">Hello!</p>

<script>
function changeText() {
document.getElementById("demo").innerText = "You changed the text!";
}
</script>

This allows you to create interactive elements directly within the lab page.
