🎧 Tutorial: "Samples - Local Loading"

1. Purpose of the Experiment

This lab page allows you to upload your own audio files directly from your device— whether they be individual sounds, samples, or entire collections from the /samples folder.

The browser doesn't have direct access to the file system: you only allow reading of files you manually select via <input type="file">. This restriction is built into the security system to prevent web pages from accessing personal directories.

2. How Loading Works

After selecting files, the input element passes the FileList array. The code loops through it, creating a visual list and a "Play" button for each file. 

fileEl.addEventListener('change', async (e) => {
const files = Array.from(e.target.files);
list.innerHTML = '';
for (const f of files) {
const el = document.createElement('div');
el.className = 'sample';
el.textContent = f.name;
const play = document.createElement('button');
play.textContent = 'Play';
el.appendChild(play);
list.appendChild(el);
}
});

This creates a dynamic gallery—a small catalog of your sounds.

3. Playback via the Web Audio API

For each file, when the button is clicked, an AudioContext object is created, in which the audio is decoded and played as a buffer. 

play.addEventListener('click', async () => {
if (!ctx) ctx = new (window.AudioContext || window.webkitAudioContext)();
const arr = await f.arrayBuffer();
const buf = await ctx.decodeAudioData(arr.slice(0));
const s = ctx.createBufferSource();
s.buffer = buf;
s.connect(ctx.destination);
s.start();
});

Here, the browser converts the file's bytes into a digital waveform. The audio isn't streamed, but downloaded in its entirety, allowing the player to precisely control its beginning and end.

4. Expansion Possibilities

— Add frequency visualization with AnalyserNode to create a live spectrum. — Or assign each sample its own volume, panorama, and filter. — You can combine multiple buffers into a single mix and build multi-layered collages.

So a simple download becomes the first step toward your own digital studio.

5. Why "local"?

Because it's reminiscent of old analog experiments: everything is nearby, at your fingertips. Sound becomes personal material, not downloaded from the cloud. Each WAV is a fragment of memory, and the lab allows you to listen to them as parts of an acoustic biography.
