🎶 Tutorial: "Generator - Chaos and Melody"

1. The Generator's Idea

This generator creates short melodic phrases where chaotic randomness obeys a simple rule: the steps are limited to a set of notes (for example, a pentatonic scale) and an offset of ±1.

Thus, despite the randomness, the sequence remains harmonious and musical.

2. Generating the Sequence

const scale = [0,2,4,7,9]; // pentatonic scale
let seq = [];
let cur = 0;
for(let i=0;i<12;i++){
const step = (Math.random()*3|0) - 1; // -1,0,+1
cur = Math.max(0, Math.min(scale.length-1, cur + step));
seq.push(scale[cur]);
}

Algorithm: each subsequent step is shifted by -1, 0, or +1 within the array of valid notes. The result is a "chaotic" but melodically meaningful phrase.

3. Playback via the Web Audio API

For each note, an oscillator and a small ADSR envelope signal are created. 

const ctx = new (window.AudioContext||window.webkitAudioContext)();
let t = ctx.currentTime;
for(let s of seq){ 
const o = ctx.createOscillator(); 
const g = ctx.createGain(); 
o.type='sine'; 
o.frequency.value = 440*Math.pow(2,(60 + s -69)/12); 
o.connect(g); 
g.connect(ctx.destination); 
g.gain.value=0.0001; 
o.start(t); 
g.gain.linearRampToValueAtTime(0.14, t+0.01); 
g.gain.exponentialRampToValueAtTime(0.0001, t+0.22); 
o.stop(t+0.28); 
t += 0.32;
}

Here, each note "fires" with a smooth rise and fall—the result is a musical phrase.

4. Experimenting with Chaos

You can change the steps, the length of the sequence, and the note set (for example, adding chromaticism). By experimenting with constraints, you control chaos and create unique melodies.
