Tutorial: Pentatonic Triad Dream

Synthesizer Description

This synthesizer creates musical "dreams" from three-note chords (triads) based on the pentatonic scale. Each triad is processed with an envelope, breath, and phase shift, and phrases are seamlessly connected via a crossfade with reverb.

Interface Elements

  • Dream Name: Enter any word or phrase to generate a unique dream.
  • ▶ Generate Dream: Creates and plays a musical dream.
  • ⏹ Stop: Stops playback.
  • Crossfade: Smooth transition between triads (0.1–2 sec).
  • Attack: Note volume rise time (0.01–1 sec).
  • Release: Note decay time (0.05–2 sec).
  • Key: Displays the base frequency of the triad.
  • Canvas: Real-time visualization of the sound wave.

How it works

  1. The name string is converted to a numeric seed for repeatable generation.
  2. A sequence of triads is generated: root note + third + fifth.
  3. An envelope (attack/release), breath, and phase shift are applied.
  4. Phrases are connected via crossfade and enhanced with reverb.
  5. The wave is visualized on the canvas with shimmering colors.

Tips Experiments

  • Change the dream name to create unique melodic variations.
  • Experiment with crossfade, attack, and release for different "breathing" and smoothness effects.
  • Follow the visualization—it shows the dynamics and intensity of the sound.
  • Combine with other sliders to create a meditative atmosphere or background music.

Usage example

Enter the dream name: Summer Evening, set the crossfade to 0.7, attack to 0.15, release to 0.9, and press ▶. Enjoy smooth triads with soft reverb.
