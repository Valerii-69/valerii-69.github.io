Manual: Pentatonic Dream

Synthesizer Description

This synthesizer creates stereo, triadic melodies based on the pentatonic scale. It uses the dream name to generate random but repeatable melodies with a specified base note, tempo, pan, attack, and decay. You can also save a dream as a WAV file.

Interface Elements

  • Dream Name: A string that defines a unique melody.
  • Base Note: Select from the pentatonic scale (C, D, E, G, A).
  • Tempo (BPM): The playback speed of the melody.
  • Crossfade: Smooth transition between notes/phrases.
  • Attack/Release: Adjusts the envelope of each note.
  • Panorama: The position of the sound in stereo (left/right side).
  • Generate Dream: Creates a melody and visualization on canvas.
  • Write WAV: Saves the current dream to a WAV file.
  • Canvas: Displays a visualization of sound waves with a dynamic background.
  • Key: Shows the base note and tempo.

How it works

  1. The dream name is converted into a numeric seed for repeatable random number generation.
  2. The octave is determined based on the ratio of vowels and consonants.
  3. A frequency array for the pentatonic scale is created.
  4. An audio buffer with three-note phrases with attack and decay envelopes, panning, and reverb is generated.
  5. The audio buffer is played through the AudioContext, and the waveform Visualized on canvas.
  6. You can export the audio buffer to a WAV file.

Tips for Experimentation

  • Change the sleep name to create unique melodies.
  • Experiment with the base note—it changes the key of the entire melody.
  • Smoothly adjust the attack and release for a softer or sharper sound.
  • Use crossfade to create smooth transitions between phrases.
  • Panorama creates the feeling of sound moving in space.
  • Tempo affects the duration of phrases and rhythm.
  • Save your favorite melodies as WAV files for later listening or analysis.

Usage Example

Enter Dream title: Night Wind, select base note: E, tempo 100 BPM. Click Generate Dream. After listening, click Record WAV to save the file.

Main Functions

  • stringToSeed(str): Converts a dream name to a numeric seed for the random number generator.
  • seededRandom(seed): Returns a repeatable pseudo-random number generator.
  • parseDreamName(name): Parses a dream name, determines octave, reverb, phrase length, and crossfade.
  • noteToFreq(note, octave): Converts a note and octave to a frequency.
  • generateDreamAudio(params): Creates an audio buffer with three-note phrases.
  • playDream(buffer): Plays an audio buffer with visualization on the canvas.
  • exportWav(buffer): Saves the current dream to a WAV file.
