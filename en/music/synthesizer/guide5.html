Tutorial: Three-Part Pentatonic Son

Synthesizer Description

This synthesizer creates stereo three-part melodies based on the pentatonic scale. Each son is formed as a sequence of three-note chords with a smooth attack/decay, panning, and reverb. You can also save the result as a WAV file.

Interface Elements

  • Dream Name: Enter any string—the synthesizer will create a unique melody.
  • Generate Dream: Creates and plays a dream based on the entered name.
  • Save WAV: Saves the current dream in WAV format.
  • Canvas: Displays a real-time waveform visualization with color effects.
  • Key: Shows the base frequency of triads.

How it works

  1. The name string is converted into a numeric seed for repeatable generation.
  2. Generates a sequence of three-note pentatonic chords scales.
  3. An attack/release envelope is applied for smoothness.
  4. Panorama is added for a stereo effect and reverb.
  5. Visualization displays the dynamics of the sound and smoothly changes the background.
  6. Multiple triads can be combined using crossfades.
  7. The result can be played back or recorded as a WAV file.

Tips for Experimentation

  • Change the dream title—each variant creates a unique melody.
  • Observe the visualization: it reflects the rhythm and amplitude of the sound stream.
  • Experiment with different title lengths and the number of vowels—this affects phrase length, reverb, and crossfades.
  • Use a WAV recording for Analyze or save your favorite tunes.

Main Functions

  • stringToSeed(str): Converts the name string to a numeric seed for generating random numbers.
  • seededRandom(seed): Returns a pseudo-random number generator function for repeatable generation.
  • parseDreamName(name): Parses the dream name, determines the base frequency, melody length, number of dreams, and reverb.
  • generateDream(freqBase, scale, duration, rand): Creates three-part melodies with panning and envelope.
  • addReverb(stereo, amount): Adds reverb to a stereo signal.
  • mergeDreams(dreams, crossfadeTime): Merges multiple three-part dreams with a smooth transition.
  • playBuffer(stereo): Plays a three-part dream through Audio context.
  • exportWav(stereo): Exports the current dream to a WAV file.
  • visualize(data): Visualizes the sound wave and smoothly changes the page background.
