Tutorial — "Musical Labyrinth" Synthesizer (guide1)

Briefly: this synthesizer is a 7x7 grid of cells, each cell carrying its own group of harmonics. Touching (or clicking) a cell either plays a sample or generates a combination of oscillators (synth mode). There's a transposer, fade-out control, and repeat count (effects stack).

What you'll hear

  • In synth mode, a rich sawtooth sound is heard, with each cell triggering a set of harmonics.
  • In sample mode, your loaded audio files are played back with overlapping repeats and a smooth volume decay.
  • Transpose shifts all active notes in real time, creating a choral shift effect.
  • The repeats and release parameters control layer density and fade-out length, respectively.

What you can customize and explore

Practical Ideas:
  • Increase repeats and decrease release to create a sonic "tightening" like a rhythmic pattern.
  • Set mode to sample and load short drum samples – the grid will turn into a drum machine.
  • Experiment with the transposer: smoothly moving the slider creates a glissando for all active oscillators.
  • Change the oscillator shape (sine/square/triangle) in the playSynth code – the timbre will change dramatically.

3) Playing synthesis (playSynth)

function playSynth(idx, cell) { 
const repeat = Number(repeatsSlider.value) || 1; 
const release = Number(releaseSlider.value) || 20; 
const trans = Number(transposeSlider.value) || 0; 
const baseFreq = 261.63; // C4 
const harmonics = cellHarmonics.get(cell) || [1]; 

harmonics.forEach(mult => { 
for (let i = 0; i < repeat; i++) { 
const osc = audioCtx.createOscillator(); 
osc.type = 'sawtooth'; // try 'sine','square','triangle' 
const freq = baseFreq * mult * Math.pow(2, (idx + trans) / 12); 
osc.frequency.value = freq; 

const gain = audioCtx.createGain(); 
gain.gain.setValueAtTime(0.5 / repeat, audioCtx.currentTime + i * 0.05); 
gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + i * 0.05 + release * 0.05); 

osc.connect(gain).connect(audioCtx.destination); 
osc.start(audioCtx.currentTime + i * 0.05); 
osc.stop(audioCtx.currentTime + i * 0.05 + release * 0.05); 

activeOscillators.set(osc, { idx, gain }); 
osc.onended = () => activeOscillators.delete(osc); 
} 
});
}

4) Playing samples (playSample)

async function playSample(idx) { 
if (!buffers.length) return; 
const repeat = Number(repeatsSlider.value) || 1; 
const release = Number(releaseSlider.value) || 20; 
const buffer = buffers[idx % buffers.length]; 

for (let i = 0; i < repeat; i++) { 
const src = audioCtx.createBufferSource(); 
src.buffer = buffer; 
const gain = audioCtx.createGain(); 
gain.gain.setValueAtTime(1, audioCtx.currentTime + i * 0.05); 
gain.gain.exponentialRampToValueAtTime(0.001, audioCtx.currentTime + i * 0.05 + release * 0.05); 
src.connect(gain).connect(audioCtx.destination); 
src.start(audioCtx.currentTime + i * 0.05); 
}
}

Tips and Tips

  • If the browser blocks sound, call audioCtx.resume() in response to a user click/tap.
  • To reduce CPU usage, replace fractal visualization with a simple canvas pattern or disable it altogether.
  • To control the tone more musically, store pre-calculated frequencies (in hertz) for each cell instead of the idx index.
  • Add a BiquadFilterNode before the destination exit to soften the high spectrum of the sawtooth.

Short checklist for testing

  • Click New — the grid has received harmonics (colors too).
  • Click a cell in synth mode — a tone should sound.
  • Switch to sample, load at least one file — when you tap Play the recording.
  • Turn the transposer - the active oscillators change pitch.
  • Press Stop - all oscillators should stop.
