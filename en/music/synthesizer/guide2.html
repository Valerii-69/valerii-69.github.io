🎧 Guide 2 — Notes and ADSR

What this synthesizer does

This synthesizer lets you hear how a note with a dynamic envelope is born from a simple waveform. Each press of the Play Note button generates a selected frequency (for example, A4 = 440 Hz) and creates a sound wave of the specified type—sine, square, sawtooth, triangle, or trapezoid.

The main idea is to explore how the ADSR (Attack, Decay, Sustain, Release) parameters shape the character of a sound. This is a model of how loudness develops over time: from a soft onset to a decay after the note is released.

What you can hear and adjust

Select a note (A2–A5), change the waveform type and ADSR parameters. Try a short Attack and a long Release - the sound will become more "singing." Increase Decay and decrease Sustain - to get the characteristic "thump" of a keyboard instrument.

4. ADSR Envelope Drawing


function drawEnvelope(a, d, s, r) { 
const width = envCanvas.width; 
const height = envCanvas.height; 
const total = a + d + r + 0.2;

ectx.beginPath();
ectx.moveTo(0, height);
ectx.lineTo(width * (a / total), 0);
ectx.lineTo(width * ((a + d) / total), height * (1 - s));
ectx.lineTo(width * ((a + d + 0.2) / total), height * (1 - s));
ectx.lineTo(width, height);
ectx.stroke();
}

Summary

This synthesizer is a simple laboratory for studying sound dynamics. Here you can observe how the geometry of the waveform combines with the temporal structure of ADSR. Ideal for experimenting with the perception of attack, decay and release.
