Tutorial: Pentatonic Dream Generator

Synthesizer Description

Synthesizer 7 creates multiple pentatonic dreams, combines them with a crossfade, adds reverb, and visualizes the result on the canvas. Each playback creates a unique combination of sounds that can be saved as a WAV file.

Interface Elements

  • Number of Dreams: The number of individual melodies that will be combined.
  • Dream Duration (sec): The duration of each melody.
  • Reverb Strength: The intensity of the reverb effect.
  • Crossfade Speed ​​(sec): The smoothness of the transition between melodies.
  • Generate and Play: Creates a combined melody, visualizes it, and plays it.
  • Canvas: Displays a visualization of the sound waves.
  • Download WAV: A link appears to save the combined melody. sleep.

How it works

  1. Random base frequencies are generated for each melody.
  2. A random pentatonic scale is selected for each sleep.
  3. An audio buffer with sine waves is created.
  4. Reverb is applied for depth.
  5. Melodies are combined with a specified crossfade.
  6. Rendered on canvas.
  7. Played via AudioContext and a WAV download link is provided.

Experimenting tips

  • Increase the number of sleeps for a more complex melody texture.
  • Vary the sleep duration for short or long sleeps phrases.
  • Use reverb to create space and atmosphere.
  • Try different crossfade values ​​for smoother or sharper melodic transitions.
  • Each playback creates a unique dream thanks to random base frequencies and scale selection.

Usage example

Set the number of dreams to 5, the duration to 3 seconds, the reverb to 0.3, and the crossfade to 0.5. Click 🎧 Generate and play. After listening, a link 💾 Download WAV will appear.

Main Functions Synthesizer

  • generateDream(freqBase, scale, duration): Creates a single pentatonic melody.
  • addReverb(signal, amount): Applies a simple reverb.
  • mergeDreams(dreams, crossfadeTime): Combines multiple melodies with a crossfade.
  • visualize(canvas, buffer): Displays the audio amplitude on the canvas.
  • encodeWAV(samples, sampleRate): Converts the audio buffer to a WAV file for downloading.
