HTML+JS Demo

Below is an interactive block where clicking generates a random number. This is a simple demonstration of dynamic interaction with the user using JavaScript.

Click me

// Get references to page elements
const demoBox = document.getElementById('demoBox');
const resetBtn = document.getElementById('resetBtn');

// Function to generate a random number from 1 to 100
function randomNumber() {
  return Math.floor(Math.random() * 100) + 1;
}

// Click handler for the demo box
demoBox.addEventListener('click', () => {
  demoBox.textContent = randomNumber();
});

// Click handler for reset button
resetBtn.addEventListener('click', () => {
  demoBox.textContent = 'Click me';
});

// Keyboard accessibility (Enter or Space)
demoBox.addEventListener('keydown', (event) => {
  if(event.key === 'Enter' || event.key === ' ') {
    event.preventDefault();
    demoBox.textContent = randomNumber();
  }
});
Code explanation:
  • getElementById — finds an element by ID on the page.
  • Math.random() generates a number from 0 to 1 (excluding 1).
  • Math.floor() rounds down to the nearest integer.
  • Event handlers click and keydown trigger functions on click or key press.
  • Attributes tabindex and role="button" make the block accessible via keyboard navigation.
  • event.preventDefault() prevents default browser behavior (like scrolling on space).
