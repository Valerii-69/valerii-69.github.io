Аудиоуправляемый фрактальный визуализатор

Для создания списка персональных фракталов необходимо:
1.Просмотреть список предлагаемых фракталов
2.Выбрать фрактал для персонального списка
3.Установить параметры в панели управления
4.Нажать кнопку SET
5.Нажать кнопку SAVE
6.Повторить эту последовательность операций для следующего фрактала
